# Fonts
私のWebサイトや制作物で使用するために作成した合成フォントを保管しておくためのリポジトリです。

## Nercone Sans CJK/JP/SC/TC/KR
InterとNoto Sans JP/SC/TC/KRの合成フォントです。

## Nercone Serif CJK/JP/SC/TC/KR
CharterとNoto Serif JP/SC/TC/KRの合成フォントです。

SIL Open Font License Version 1.1 ライセンスの元で自由に使用できます。

## Nercone Mono CJK/JP/SC/TC/KR
MesloLGSとNoto Sans JP/SC/TC/KRの合成フォントです。
ラテン文字と日本語文字が1:2の幅になるよう調整されています。

SIL Open Font License Version 1.1 ライセンスの元で自由に使用できます。

## Nercone Mono CJK/JP/SC/TC/KR NF
